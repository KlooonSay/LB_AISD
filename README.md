# Лабораторные работы по дисциплине «Алгоритмы и структуры данных»

Вариант 5.

Репозиторий содержит 9 лабораторных работ, выполненных на языке C++.

## Структура репозитория

- `Lab1/lab01.cpp` — массивы автоматические, статические и динамические
- `Lab2/lab02.cpp` — массивы и структурированные типы данных
- `Lab3/lab03.cpp` — файлы
- `Lab4/lab04.cpp` — очереди и стеки
- `Lab5/lab05.cpp` — связные списки
- `Lab6/lab06.cpp` — сортировка массивов
- `Lab7/lab07.cpp` — сортировка списков
- `Lab8/lab08.cpp` — поиск в массивах и списках
- `Lab9/lab09.cpp` — двоичные деревья

## Сборка и запуск

Каждая лабораторная работа является самостоятельной программой.

Для сборки требуется компилятор с поддержкой C++17.

Пример сборки и запуска лабораторной работы №1:

```bash
clang++ -std=c++17 Lab1/lab01.cpp -o lab01
./lab01
```

Для остальных лабораторных работ достаточно заменить номер папки и имя исходного файла.

Например, для лабораторной работы №6:

```bash
clang++ -std=c++17 Lab6/lab06.cpp -o lab06
./lab06
```

## Дополнительные файлы

Для запуска большинства лабораторных работ дополнительные файлы не требуются.

Лабораторная работа №3 самостоятельно создаёт файлы:

- `students.txt`
- `students.bin`

После записи программа повторно открывает эти файлы, считывает данные и проверяет их совпадение с исходными значениями.

## Проверочные данные

Исходные данные для демонстрации работы алгоритмов уже заданы непосредственно в программах.

В лабораторных работах предусмотрены проверки основных сценариев:

- переполнение очередей и стеков;
- различные варианты сортировки;
- успешный и неуспешный поиск;
- вставка и удаление элементов;
- различные способы обхода дерева.

Каждую лабораторную работу можно запускать отдельно.
